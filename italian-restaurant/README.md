# La Dolce Vita - 意式餐厅网站项目

这是一个为现代意式餐厅设计的响应式单页网站（SPA）模板。它旨在提供优雅的用户体验，同时满足餐饮业的核心业务需求。

## 1. 网站结构与页面规划

本项目采用单页滚动设计（Single Page Application Style），以适应现代用户的浏览习惯，特别是移动端用户。

*   **Header (导航)**: 包含品牌 Logo 和主要功能链接（主页、关于、菜单、预订、联系）。移动端自动折叠为汉堡菜单。
*   **Hero Section (首屏)**: 高质量全屏背景图 + 醒目的 Slogan + "立即预订" CTA 按钮。
*   **About Us (关于我们)**: 简短的品牌故事和主厨介绍，配以高质量图片。
*   **Menu (在线菜单)**: 
    *   交互式分类 Tab（全部、前菜、主菜、披萨、甜点）。
    *   特色菜品高亮展示。
    *   清晰的价格和描述。
*   **Reservation (在线预订)**: 简洁的表单，包含必要的字段（姓名、电话、日期、时间、人数、备注）。
*   **Contact & Map (联系与地图)**: 地址、电话、社交媒体链接、营业时间以及地图嵌入。
*   **Footer (页脚)**: 版权信息。

## 2. 视觉设计

### 配色方案 (Color Palette)
我们选择了经典的意式配色，营造温暖、诱人且专业的氛围：
*   **Primary (主色)**: `#C41E3A` (Cardinal Red) - 代表番茄酱、红酒和热情。
*   **Secondary (辅色)**: `#556B2F` (Dark Olive Green) - 代表橄榄油、罗勒和新鲜食材。
*   **Accent (强调色)**: `#D4AF37` (Gold) - 用于星级评价、图标和强调文字，增添高级感。
*   **Background (背景)**: `#FDF5E6` (Old Lace) - 温暖的米白色，模仿旧菜单纸张或面团的质感，比纯白更护眼且有格调。
*   **Text (文本)**: `#333333` (Charcoal) - 深炭灰，确保阅读清晰度。

### 字体 (Typography)
*   **Heading**: `Playfair Display` - 衬线体，优雅、传统，非常适合餐饮品牌标题。
*   **Body**: `Lato` - 无衬线体，现代、易读，适合正文和菜单描述。

## 3. 移动优先与响应式设计

代码采用 Mobile-First 策略编写：
*   使用 Flexbox 和 CSS Grid 实现自适应布局。
*   导航栏在移动端自动转换为侧滑或下拉式菜单。
*   表单元素在触屏设备上进行了优化（如增大点击区域）。
*   图片使用 `max-width: 100%` 确保不溢出容器。

## 4. 后台管理 (CMS) 建议

为了方便餐厅工作人员更新菜单和查看预订，建议采用以下轻量级 CMS 方案，避免复杂的服务器维护：

### 方案 A：Headless CMS (推荐)
使用 **Strapi** 或 **Contentful**。
*   **优点**: 内容管理界面友好，API 丰富，前端可以通过 fetch 动态获取菜单数据。
*   **适用**: 需要频繁更新内容，且有一定的技术预算。

### 方案 B：基于 Git 的 CMS (最简易)
使用 **Netlify CMS (Decap CMS)** 配合静态站点生成器 (如 Hugo/Jekyll) 或纯 HTML。
*   **优点**: 免费，直接部署在 Netlify/Vercel 上，内容存储在 GitHub 中。
*   **适用**: 技术团队维护，成本最低。

### 方案 C：Google Sheets 作为后端 (极简)
利用 **SheetDB** 或类似服务，将 Google 表格作为数据库。
*   **优点**: 餐厅经理最熟悉的操作界面（Excel/表格），零学习成本。前端 JS 直接读取表格数据渲染菜单。
*   **适用**: 小微型餐厅，预算有限。

## 5. 地图与社交整合

*   **地图**: 代码中预留了 `iframe` 占位符。实际部署时，请在 Google Maps 或 百度地图 生成嵌入代码并替换。
*   **社交媒体**: 提供了 WeChat, Instagram, Facebook 的图标链接，建议链接到餐厅的官方主页。

## 6. 如何运行

本项目包含后端服务，请按照以下步骤运行：

1.  **安装依赖**:
    ```bash
    npm install
    ```

2.  **初始化数据库** (仅需运行一次):
    确保本地 MySQL 服务已启动，且密码为 `hellohello@2025`。
    ```bash
    node db_setup.js
    ```

3.  **启动服务器**:
    ```bash
    node server.js
    ```

4.  **访问网站**:
    打开浏览器访问 [http://localhost:3000](http://localhost:3000)
